## ¿Qué es un proyecto?

Un proyecto es un esfuerzo temporal que se realiza para crear un producto, servicio o resultado único.

- Tiene un inicio y un final definidos.
- Surge para satisfacer una necesidad y alcanzar determinados objetivos.
- Termina cuando se cumplen los objetivos, cuando estos ya no pueden cumplirse o cuando desaparece la necesidad que lo originó.
- Todo proyecto tiene un alcance y busca generar resultados concretos.

**Ideas clave:**
*Esfuerzo temporal + Producto/Servicio/Resultado + Objetivos + Necesidad + Alcance*.


![[Pasted image 20260810063223.png]]

- Temporal no significa que sea de corta duración; puede durar mucho tiempo.
- Generalmente, un proyecto busca crear un resultado duradero.
- Los entregables del proyecto no necesariamente son temporales.
- Puede contener actividades repetitivas, pero esto no cambia su naturaleza única y no repetitiva.
- Un proyecto busca pasar de una situación actual a una situación esperada, solucionando un problema.

**Ideas clave:**
*Proyecto + Situación actual + Problema + Situación esperada + Duración + Resultado + Elementos*

## Ejemplo de proyectos

- Desarrollo de un nuevo producto o servicio.

- Cambio en la estructura, plantilla o estrategia de una empresa.

- Desarrollo de un nuevo sistema informático o su modificación.

- Construcción de un edificio o infraestructura.

- Implementación de un nuevo modelo de negocio.

## Impacto de los proyectos

Los proyectos pueden generar diferentes tipos de impactos en la sociedad y en el entorno:

- **Impactos sociales:** afectan la calidad de vida, el empleo, la educación y el bienestar de las personas.
- **Impactos económicos:** pueden generar ingresos, reducir costos, crear empleos o impulsar el crecimiento económico.
- **Impactos ambientales:** pueden beneficiar o afectar el medio ambiente, por ejemplo, mediante el uso de recursos, contaminación o reducción de residuos.

## ¿Qué genera un proyecto?

Un proyecto puede generar diferentes tipos de resultados o entregables:

- **Un componente de otro elemento:** forma parte de un producto o sistema más grande.
- **Un elemento final en sí mismo:** es el resultado completo que se busca obtener.
- **La capacidad de realizar un servicio:** permite ofrecer o realizar una determinada actividad.
- **Un producto o documento:** genera un resultado tangible que sirve como evidencia del proyecto.

**Ideas clave:**
*Producto + Servicio + Tangible + Resultado + Evidencia*.

## La triple restricción

La Triple Restricción establece que un proyecto debe gestionarse considerando tres elementos principales:

- **Alcance:** define qué se debe hacer y si el proyecto cumple con las especificaciones.
- **Tiempo:** indica cuánto tiempo se tiene para ejecutar y entregar el proyecto.
- **Costo:** corresponde al presupuesto y recursos económicos disponibles.

Estos tres elementos están relacionados entre sí: si se modifica uno, normalmente se genera un impacto en los otros. Por ejemplo, aumentar el alcance puede requerir más tiempo o mayor costo.

---

## Ejemplos

- **Proyecto de un periódico:** creación y puesta en funcionamiento de un nuevo diario.
- **Proyecto de una UCI:** implementación o construcción de una Unidad de Cuidados Intensivos.
- **Lanzamiento de un nuevo producto:** desarrollo y lanzamiento de un producto al mercado.
- **Mejoramiento de un producto:** modificación de un producto existente para mejorar sus características o funcionamiento.

---

## Equilibrar las restricciones

Las restricciones de alcance, tiempo y costo están relacionadas. Si una cambia, las demás pueden verse afectadas.

- Aumentar el tiempo del proyecto puede requerir:
    - Mayor presupuesto.
    - Recursos adicionales.
    - O reducir el alcance o la calidad.
- Cambiar los requisitos del proyecto puede provocar un aumento de los riesgos.

## Restricción extendida

Además de la triple restricción, un proyecto debe considerar otras restricciones que pueden afectar su ejecución:

- **Alcance:** qué se debe realizar.
- **Tiempo:** cuándo debe terminar.
- **Costo:** presupuesto disponible.
- **Calidad:** nivel de cumplimiento y características esperadas.
- **Recursos:** personas, equipos y materiales necesarios.
- **Riesgos:** situaciones que pueden afectar negativamente el proyecto.

Las especificaciones del proyecto influyen en estas restricciones, por lo que el gerente del proyecto debe equilibrarlas y controlarlas para lograr los objetivos.

## ¿Qué es gerencia de proyectos? (Bajo el enfoque del PMI)

La gerencia o dirección de proyectos consiste en aplicar conocimientos, habilidades, herramientas y técnicas a las actividades del proyecto para cumplir sus requisitos y objetivos.

Según el enfoque del PMI, se logra mediante la correcta integración de los procesos de dirección de proyectos.

- **Conocimientos:** saber cómo gestionar un proyecto.
- **Habilidades:** capacidad para organizar, dirigir y tomar decisiones.
- **Herramientas y técnicas:** métodos utilizados para planificar y controlar el proyecto.

---

## ¿Qué es gerencia de proyectos?

La gerencia de proyectos es la disciplina encargada de organizar, dirigir y controlar las actividades necesarias para alcanzar los objetivos de un proyecto.

- Los proyectos son únicos, por lo que requieren una forma de gestión diferente a las operaciones rutinarias de una organización.
- La gerencia debe utilizar habilidades y competencias específicas para planificar y ejecutar el proyecto correctamente.
- Para realizar las actividades se utilizan diferentes recursos, como:
    - Tiempo
    - Dinero
    - Personas o talento humano
    - Materiales
    - Comunicación
- Todos estos recursos deben ser coordinados para lograr los objetivos previamente establecidos.

**Ideas clave:**
*Gerencia + Actividades + Recursos + Talento humano + Comunicación + Objetivos*.

---

## Gerencia de proyectos

El Equipo del proyecto debe:
- Seleccionar los procesos apropiados (Idóneos)
- Usar un enfoque definido
- Cumplir con los requerimientos
- Balancear las demandas de competencia entre Alcance, Tiempo, Costo, Calidad, Recursos y Riesgos

---

## ¿Qué implica la dirección de proyectos?

La dirección de proyectos implica principalmente:

- **Identificar los requisitos:** conocer qué necesita el proyecto para cumplir con sus objetivos.

- **Considerar a los interesados:** tener en cuenta sus necesidades, inquietudes y expectativas durante la planificación y ejecución.

- **Equilibrar las restricciones:** administrar aspectos como:
    - **Alcance**
    - **Calidad**
    - **Cronograma (tiempo)**
    - **Presupuesto**
    - **Recursos**
    - **Riesgos**
- Estas restricciones están relacionadas, por lo que si una cambia, al menos otra puede verse afectada.

## Proyectos y planeación estratégica

Los proyectos se autorizan y desarrollan cuando existe una necesidad o una oportunidad que está relacionada con los objetivos estratégicos de una organización.

Las principales razones para iniciar un proyecto son:

- **Demanda del mercado:** responder a lo que los clientes o el mercado necesitan.
- **Oportunidad estratégica:** aprovechar una oportunidad para mejorar o crecer.
- **Necesidad comercial:** solucionar una necesidad del negocio.
- **Solicitud de un cliente:** desarrollar algo solicitado directamente por un cliente.
- **Adelantos tecnológicos:** aprovechar nuevas tecnologías o innovaciones.
- **Requisitos legales:** cumplir nuevas leyes, normas o regulaciones.
- **Motivación personal:** proyectos impulsados por intereses o iniciativas de las personas.

## Ciclo de vida del proyecto

El ciclo de vida del proyecto es el conjunto de fases en las que se divide un proyecto para facilitar su planificación, ejecución y control. Estas fases pueden ser secuenciales o superpuestas.

Las principales fases son:

1. **Iniciación / Factibilidad:** se evalúa si el proyecto es **técnica y económicamente viable** y si vale la pena realizarlo.
2. **Planificación:** se define **qué se hará, cómo, cuándo, con qué recursos y presupuesto**.
3. **Implementación / Ejecución:** se realizan las actividades planificadas y se desarrolla el **producto o resultado**.
4. **Control:** se verifica el **avance**, los costos, el tiempo, el alcance y la calidad, realizando ajustes cuando sea necesario.
5. **Cierre:** se finaliza el proyecto, se realiza la **entrega y aprobación del producto**, y se cierran los documentos y actividades pendientes.

**Costos y personal:** normalmente son bajos al inicio, aumentan durante la ejecución y disminuyen al finalizar.
 
*Iniciación → Planificación → Ejecución → Control → Cierre*

## Factibilidad financiera, técnica y operativa

La factibilidad financiera busca determinar si el proyecto es económicamente viable, organizando y analizando las inversiones, costos e ingresos necesarios.

**Sistematización financiera:** consiste en identificar y ordenar toda la información económica obtenida de los estudios previos para evaluar el proyecto.

Se consideran principalmente:

- **Necesidades totales de capital:** dinero necesario para poner en marcha y desarrollar el proyecto.
- **Requerimiento total de activos:** determina en qué se utilizarán los recursos disponibles.
- **Activos fijos tangibles e intangibles:** se detallan los bienes y recursos que serán utilizados en el proyecto, tanto físicos como no físicos.

![[Pasted image 20260810072016.png]]

---

### Técnica

Se refiere a los recursos, conocimientos, habilidades, experiencia, herramientas y equipos necesarios para realizar las actividades del proyecto.

La factibilidad técnica determina si se cuenta con los recursos y capacidades necesarias para desarrollar e implementar el proyecto. Si no se tienen, se evalúa si pueden obtenerse o desarrollarse a tiempo.

---

### Operativa

Se refiere a los recursos humanos y actividades necesarios para que el proyecto funcione correctamente.

La factibilidad operativa evalúa si existen las personas y condiciones necesarias para implementar, utilizar y mantener el sistema, y si este realmente funcionará una vez instalado.

---

#### Conclusión

La factibilidad financiera evalúa si una solución puede funcionar correctamente dentro de una organización y si será aceptada por las personas.

Considera:

- Que exista personal capacitado para desarrollar y utilizar el proyecto.
- Que los usuarios finales estén dispuestos a usar el sistema o servicio.
- La urgencia del problema y la aceptación de la solución.

## Interesados (Stakeholders)

Son las personas, grupos u organizaciones que participan en un proyecto o que pueden verse afectados positiva o negativamente por sus resultados.

Pueden ser, por ejemplo, clientes, usuarios, empleados, directivos, proveedores o instituciones.

Además, los stakeholders pueden influir en las decisiones, actividades, entregables y resultados del proyecto, por lo que es importante identificar sus intereses y necesidades.

## Interesados

Son las personas, grupos u organizaciones que participan en el proyecto, pueden verse afectados por él o tienen capacidad para influir en sus decisiones y resultados.

 1. *Clientes*

Son quienes utilizarán el producto, servicio o resultado del proyecto. Puede haber diferentes tipos de clientes según el proyecto.  
**Ejemplo:** médicos, pacientes y entidades que pagan por un producto farmacéutico.

### 2. Sponsor (Patrocinador)

Es la persona o grupo que **proporciona los recursos económicos** para realizar el proyecto. Es fundamental porque puede apoyar al proyecto y actuar como **representante ante la dirección de la empresa**.

### 3. Program Manager (Gestor de programas)

Se encarga de **coordinar varios proyectos relacionados entre sí**. Cuando un proyecto forma parte de un programa, puede ser el **jefe directo del Project Manager**.

### 4. Equipo

Está formado por el **Project Manager y las personas que realizan el trabajo del proyecto**. En proyectos grandes puede existir un equipo específico de gestión. Los miembros del equipo se encargan principalmente de ejecutar las actividades, no necesariamente de gestionarlas.

### 5. Director Funcional

Son los responsables de **áreas de la organización**, como Recursos Humanos, Calidad o el área Legal. Pueden aportar **personal, materiales, conocimientos**, establecer requisitos y determinar aspectos relacionados con la calidad o las normas legales.

### 6. Director de Operaciones

Gestiona las áreas relacionadas directamente con la **producción o venta de los bienes y servicios** de la empresa. Puede proporcionar recursos, participar en los requisitos y recibir el producto terminado para llevarlo a la operación.

### 7. Proveedores / Business Partners

Son **empresas externas** que tienen una relación contractual o de colaboración con el proyecto. Pueden aportar **recursos, conocimientos, experiencia, materiales o servicios** necesarios para desarrollar el proyecto.

### 8. Project Manager

Es uno de los stakeholders más importantes y es el **responsable de dirigir el proyecto y contribuir a su éxito**. Entre sus principales responsabilidades están:

- **Desarrollar el plan del proyecto.**
- Mantener el proyecto de acuerdo con el **presupuesto y cronograma**.
- Garantizar la **calidad** establecida.
- **Identificar, controlar y responder a los riesgos.**
- Elaborar y proporcionar **métricas e informes periódicos, actuales y precisos**.
